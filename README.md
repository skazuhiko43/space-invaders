# SPACE INVADERS (retro clone)

VS Code で編集・実行できる、外部ライブラリ不要のバニラ HTML/CSS/JS 製レトロシューティングです。
**完全オフライン動作・PWA対応**(App Storeを使わずiPhoneのホーム画面にアプリとして追加できます)。

## ファイル構成

```
Space Invaders/
├── index.html        ← ゲーム画面・UI構造
├── style.css         ← CRT風レトロデザイン、レスポンシブ/タッチUI配置
├── game.js           ← ゲームロジック本体
├── manifest.json      ← PWA設定(アプリ名・アイコン・全画面表示など)
├── service-worker.js  ← オフラインキャッシュ(初回読込後は通信不要)
├── icons/              ← ホーム画面アイコン各サイズ
│   ├── icon-180.png
│   ├── icon-192.png
│   ├── icon-512.png
│   └── favicon-32.png
└── README.md          ← このファイル
```

このゲームは音声も含めて外部ファイル・外部通信(Webフォント等)への依存が一切ないため、
一度読み込めば **Wi-Fi/モバイル通信をすべてオフにしても動作します。**

## VS Codeでの動かし方

1. この3ファイル(index.html / style.css / game.js)をデスクトップの `Space Invaders` フォルダに入れる
2. VS Codeでそのフォルダを開く (`ファイル > フォルダーを開く`)
3. 拡張機能「**Live Server**」(作者: Ritwick Dey) をインストールしていない場合は入れる
4. `index.html` を右クリック → **「Open with Live Server」**
5. ブラウザが開いて自動的にゲームが起動します

   ※ `index.html` をダブルクリックしてブラウザで直接開くだけでも一応動きますが、
   将来的に画像や音声ファイルを追加する場合は `file://` だと読み込めないことがあるため、
   Live Server (`http://localhost:...`) 経由での起動を推奨します。

## Androidで試す(まずはこちらから)

Androidは iPhone よりシンプルに試せます。

### 一番簡単な方法: ファイルを転送してChromeで開く

1. `Space Invaders` フォルダ一式(index.html / style.css / game.js / manifest.json / service-worker.js / icons フォルダすべて)を
   スマホに転送する。やりやすい方法はどれでもOKです:
   - Googleドライブなどのクラウドストレージにアップロードしてスマホ側でダウンロード
   - USBケーブルでPCと接続してファイルをコピー
   - このチャットで受け取ったファイルをスマホのブラウザ経由でそのままダウンロード(下の「ZIPでまとめて受け取る」参照)
2. スマホの **ファイル(Files)アプリ** でフォルダを開き、`index.html` をタップ
   - 「このファイルを開くアプリ」を聞かれたら **Chrome** を選択
3. Chromeでゲームが起動することを確認
4. Chromeの **右上の ⋮ メニュー** → **「ホーム画面に追加」** をタップ
5. ホーム画面にアイコンが追加され、以降はアプリのように起動できます(Wi-Fi/データ通信オフでもOK)

### ZIPでまとめて受け取る場合

このチャットの返信で `space-invaders.zip` を渡しています。それをダウンロードし、
スマホの「ファイル」アプリで **展開(解凍)** してから、上記の手順2に進んでください
(Android標準のファイルアプリはZIPをタップするだけで展開できます)。

### より本格的にPWA化したい場合

Service Workerによる完全なオフラインキャッシュとフルスクリーン起動を確実に有効にしたい場合は、
下記の iPhone向け「方法B」と同じ考え方で、GitHub Pagesなど `https://` のホスティングを一度経由してから
「ホーム画面に追加」すると、Chromeが自動で「アプリをインストール」の案内を出してくれます。

## iPhoneにインストールする(オフライン・App Store不要)

App Storeを使わず、Safariの「ホーム画面に追加」機能だけでアプリのように使えます。
やり方は2通りあります。目的に応じて選んでください。

### 方法A: サーバー不要・一番シンプル(ずっとオフラインでOK)

PCを使わず、ファイルを直接iPhoneに送るだけの方法です。

1. `Space Invaders` フォルダ一式(index.html / style.css / game.js / manifest.json / service-worker.js / icons フォルダ)を
   **AirDrop** か **iCloud Drive**、または **Files(ファイル)アプリ** 経由でiPhoneに送る
   - Mac: フォルダを選択 → 共有 → AirDrop → 自分のiPhoneを選択
   - Windows: iCloud Driveアプリでフォルダをアップロードし、iPhoneのFilesアプリの「iCloud Drive」から見えるようにする
2. iPhoneの **Files(ファイル)アプリ** で送られたフォルダを開き、`index.html` をタップ
   - プレビューが開いたら、右上または下の **共有ボタン(□に↑)** をタップ
   - 「**Safariで開く**」を選ぶ
3. Safariでゲームが表示されたら、下部(または上部)の共有ボタンをタップ →
   「**ホーム画面に追加**」を選択 → 名前を確認して「追加」
4. ホーム画面にアイコンが追加され、以降はApp Store不要・Wi-Fi/通信オフでも起動できます

※ この方法は手軽ですが、iOSのバージョンによっては見た目がSafariのアドレスバー付きで開く場合があります
(機能・操作性には影響ありません)。全画面のアプリらしい見た目にしたい場合は方法Bをおすすめします。

### 方法B: 一番アプリらしい見た目・動作になる(初回のみネット接続が必要)

Service Worker(オフラインキャッシュ)とホーム画面追加時の全画面表示は、
`https://` または `http://localhost` として読み込んだ場合に確実に動作する仕組みです。
そのため、**最初の1回だけ** 無料のホスティングを経由するとより完成度の高いインストールができます。

1. GitHub Pages・Netlify・Vercelなど無料の静的ホスティングに、このフォルダをアップロードする
   (例: GitHubにリポジトリを作って `Space Invaders` フォルダの中身をpush → 設定でGitHub Pagesを有効化)
2. 発行された `https://〜` のURLをiPhoneのSafariで開く
3. 共有ボタン → 「ホーム画面に追加」
4. 追加したアイコンから起動すると、Safariのアドレスバーが表示されない**全画面アプリ表示**になり、
   Service Workerが全ファイルをキャッシュ済みなので、**その後は機内モードでも問題なく遊べます**

どちらの方法も審査や登録は不要で、App Store/TestFlightは一切使いません。

## 操作方法

### PC (キーボード)
- `←` `→` または `A` `D` : 移動
- `Space` または `↑` : 攻撃
- `P` : 一時停止

### スマホ・タブレット
- 自動的にタッチ操作モードになり、画面下部に仮想コントローラーが表示されます
- **画面左のスティック**をドラッグ: 左右移動
- **画面右の FIRE ボタン**: タップ/長押しで攻撃
- 縦向きで開くと「デバイスを横向きにしてください」という警告が出ます。横向きにすると自動でゲーム画面に戻ります
- 対応端末では初回タップ時に全画面化＋横向き固定を試みます(未対応ブラウザでは自動的にスキップされます)

## サウンドについて

すべてWebAudioでリアルタイム生成しており、音声ファイルは一切使っていません(容量ゼロ・完全オフライン)。

- 発射音・被弾音・撃破音・UFO撃破音・敵の移動テンポ音(残数が減るほど速くなる古典的な「ドゥンドゥン」音)
- UFO出現中はうなり音が鳴り続けます
- ゲーム開始時/ウェーブクリア時/ゲームオーバー時にそれぞれジングルが鳴ります
- 画面上部中央の **♪ ボタン** でいつでもミュート/解除できます(設定はブラウザに保存され次回起動時も保持されます)
- スマホのブラウザは「ユーザーが画面に触れるまで音を鳴らせない」仕様のため、初回タップ/キー入力時に自動で音声を有効化しています

## ゲームの仕様

- 5行×9列のエイリアン編隊。残数が減るほど動きが速くなる、ウェーブが進むほど難易度上昇
- 4つの破壊可能なバリケード(トーチカ)
- たまに画面上部を横切るUFO(撃破でボーナス得点)
- ハイスコアはブラウザの `localStorage` に自動保存
- 効果音は WebAudio で生成しているため音声ファイル不要

## カスタマイズしたいときのヒント (`game.js` 内)

| 変えたいこと | 該当箇所 |
|---|---|
| エイリアンの行数・列数 | `ROWS`, `COLS` |
| プレイヤーの移動速度・連射間隔 | `PLAYER_SPEED`, `PLAYER_FIRE_COOLDOWN` |
| 難易度の上がり方 | `updateFormation()` 内の `formation.stepInterval` 計算式 |
| 配色 | `style.css` 冒頭の `:root` 変数、`game.js` の `COLORS` |
| エイリアン/自機のドット絵 | `game.js` の `SPRITES` (`X`=描画する / `.`=空白の文字列配列) |
| バリケードの形 | `BARRIER_TEMPLATE` |

## 既知の制約

- `screen.orientation.lock()` はブラウザによっては未対応/PWA化しないと動作しない場合があります(その場合は縦向き警告表示で誘導する形にフォールバックします)
- iOS Safari は `requestFullscreen()` に一部制限があるため、横画面での見た目に多少余白が出ることがあります
